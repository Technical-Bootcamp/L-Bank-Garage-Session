# Challenge 2: Copilot Edit & Agent Mode

## Goal: Refactor a messy script and generate unit tests using Copilot Edit and Agent Mode.

Instructions:

1. Open `messy_script.py` in VS Code.
2. Use Copilot Edit Mode to refactor the script:
   - Improve readability and structure
   - Optimize performance
3. Switch to Agent Mode and ask Copilot to generate unit tests for the refactored script.
