# Challenge 3: Context-Aware Coding with MCP

## Goal: Complete a multi-file Flask app using Copilot’s context awareness

Instructions:

1. Open `app.py`, `routes.py`, and `utils.py` in VS Code.
2. Use Copilot to complete the Flask app:
   - Define routes in `routes.py`
   - Implement utility functions in `utils.py`
   - Integrate everything in `app.py`
3. Observe how Copilot uses context across files to provide suggestions.
