# Challenge 1: Prompt Engineering

## Goal: Use Copilot to build a `User` class with validation, logging, and docstrings.

Instructions:

1. Open `user_prompt.py` in VS Code.
2. Use GitHub Copilot to generate a `User` class with the following features:
   - Attributes: `username`, `email`, `age`
   - Validation: Ensure `email` is valid, `age` is a positive integer
   - Logging: Log creation and validation steps
   - Docstrings: Add docstrings for the class and methods
3. Refine prompts iteratively to achieve the desired output.
